# Aurora Rose

An example Kinora wallpaper package: the built-in Aurora with rose and violet colours. It contains no media, only settings, and is dedicated to the public domain under CC0 1.0.

To try it, zip this folder, rename the zip to `Aurora Rose.kinorawallpaper`, and drop it on Kinora's window. Or drop the folder itself. See [the format](../../docs/FORMAT.md).
